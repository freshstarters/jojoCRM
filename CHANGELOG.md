# Changelog

## [Unreleased] - 2026-11-17

### Breaking Changes
- **Mandatory environment and PostgreSQL configuration**: Switched `DATABASES['default']` from SQLite (`db.sqlite3`) to PostgreSQL (`django.db.backends.postgresql`) and required `SECRET_KEY`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`, and `DB_HOST` without fallbacks via `decouple.config(...)`; replaced `MAILERS` with SMTP-default `EMAIL_BACKEND` and `SERVER_EMAIL_*` settings (`6a8649e`; `jojoCRM/settings.py`, `.env.example`).
- **Custom user model and session middleware**: Configured `AUTH_USER_MODEL = 'mainapp.User'` and registered `ActiveSessionEnforcementMiddleware` in `MIDDLEWARE` (`6a8649e`, `a8b35e8`; `jojoCRM/settings.py`, `mainapp/middleware.py`).
- **Package restructuring of `mainapp` modules**: Replaced root `mainapp/models.py`, `mainapp/views.py`, and `mainapp/tests.py` files with `mainapp/models/`, `mainapp/views/`, and `mainapp/tests/` packages (`a8b35e8`, `4937f57`, `fb4433a`, `aa487ac`).

### Added
- **API URL routing and public endpoints**: Mounted `/api/v1/` routing and added `GET /api/v1/hello/`, `GET /api/v1/csrf/`, and `GET /api/v1/catalog/business-types/` (`6a8649e`, `4937f57`; `jojoCRM/urls.py`, `mainapp/urls.py`, `mainapp/views/public_views.py`).
- **Ghana workspace registration and IPinfo location check (S1.1)**: Implemented server-side IP resolution (`REMOTE_ADDR` and `TRUSTED_PROXY_IPS`) and fail-closed IPinfo lookup requiring `country == "GH"` with all `privacy.{vpn,proxy,tor,relay,hosting}` flags strictly `false`, reserved-slug validation, and atomic `Workspace` plus `User` creation (`7f66ac7`, `4937f57`; `mainapp/integrations/geolocation.py`, `mainapp/views/auth_views.py`, `mainapp/helpers/request_helpers.py`).
- **Email verification, password sign-in, and password reset (S1.2)**: Added `EmailActionToken` (`verify_email` 1-hour TTL, `reset_password` 15-minute TTL, SHA-256 `token_hash`, 60-second cooldown, single-use invalidation), fail-closed SMTP delivery, and `/api/v1/signup/`, `/verify-email/`, `/resend-verification/`, `/login/`, `/logout/`, `/password-reset/request/`, and `/password-reset/confirm/` endpoints (`7f66ac7`, `4937f57`, `aa487ac`; `mainapp/service/email_service.py`, `mainapp/views/auth_views.py`, `mainapp/models/core.py`).
- **Google OIDC, Microsoft OIDC, and WebAuthn passkeys (S1.3)**: Added `ExternalIdentity` and `PasskeyCredential` models, PKCE + JWKS OIDC authentication (`openid email profile` identity scopes only, keeping `mailbox_connection` unset), WebAuthn passkey registration/login/deletion, and `/api/v1/auth/providers/`, `/auth/<provider>/start|callback/`, `/auth/passkey/...`, and `/auth/methods/` endpoints (`7f66ac7`, `4937f57`, `aa487ac`; `mainapp/integrations/auth_providers.py`, `mainapp/service/passkey_service.py`, `mainapp/views/oauth_views.py`, `mainapp/views/passkey_views.py`, `mainapp/views/account_views.py`).
- **Workspace invitations and single-workspace enforcement (S1.4)**: Added `WorkspaceInvite` with SHA-256 token hashing, `INVITE_TTL_HOURS` expiration, 60-second resend cooldown, active-invite uniqueness constraints, location-free `/api/v1/invites/preview/` and `/api/v1/invites/accept/` endpoints, and `/api/v1/workspaces/<slug>/people/`, `/invites/`, and `/invites/<invite_id>/revoke/` (`7f66ac7`, `4937f57`, `aa487ac`; `mainapp/views/invite_views.py`, `mainapp/models/core.py`).
- **Owner/Staff roles, member lifecycle, account settings, and audit log (S1.5)**: Added `Role` (permanent `Owner` and default `Staff` constraints, owner-only `can_manage_seat_plan` and `can_manage_sms_wallet`, seven PRD capability switches), `AuditLog`, active seat counting, `/api/v1/account/profile/`, `/api/v1/account/password/change/`, `DELETE /api/v1/auth/providers/<provider>/`, `/api/v1/workspaces/<slug>/members/<member_id>/deactivate|reactivate/`, member hard-delete refusal, `/api/v1/workspaces/<slug>/roles/`, and paginated `/api/v1/workspaces/<slug>/audit/` (`a8b35e8`, `7f66ac7`, `4937f57`, `aa487ac`; `mainapp/service/role_service.py`, `mainapp/service/audit_service.py`, `mainapp/views/workspace_access_views.py`, `mainapp/views/workspace_views.py`).
- **20-type business catalog and workspace packs (S2.0)**: Added static catalog of 5 core objects, 25 catalog objects, and 20 business types (each mapping to 12 pack objects for 17 starter tables), Contact label presets (`Patient`, `Student or Guardian`, `Donor or Member`, `Contact`), `WorkspacePack` and `WorkspaceTable` models, and `/api/v1/workspaces/<slug>/`, `/packs/`, and `/tables/<object_key>/` endpoints with core-table (`400`) and non-empty-table (`409`) disable guards (`a8b35e8`, `7f66ac7`, `4937f57`, `aa487ac`, `4add070`; `mainapp/catalog.py`, `mainapp/service/catalog_service.py`, `mainapp/views/workspace_views.py`).

### Security
- **Active session enforcement and revocation**: Added `User.session_version`, `user_logged_in` signal binding, `invalidate_user_sessions`, and `ActiveSessionEnforcementMiddleware` to log out deactivated users and stale sessions across requests, password changes, and password resets (`a8b35e8`, `7f66ac7`; `mainapp/middleware.py`, `mainapp/signals.py`, `mainapp/service/session_service.py`).
- **Cross-workspace isolation and fail-closed provider checks**: Enforced workspace scoping across record CRUD, linked-record validation, activity targets, and role updates, and ensured missing IPinfo, SMTP, or OAuth credentials fail closed rather than bypassing checks (`7f66ac7`, `4add070`, `99fec81`).

### Upgrade & Deployment Notes
- **Environment file setup**: Create `.env` from `.env.example` and supply required `SECRET_KEY`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`, and `DB_HOST` values (plus `IPINFO_TOKEN`, `SERVER_EMAIL`/`SERVER_EMAIL_PASSWORD`, Google/Microsoft OAuth credentials, and `WEBAUTHN_*` / `APP_BASE_URL` for full feature operation).
- **Database provisioning and migrations**: Because `mainapp/migrations/*` is excluded in `.gitignore` and only `mainapp/migrations/__init__.py` is tracked, create a PostgreSQL database and run `python manage.py makemigrations mainapp` followed by `python manage.py migrate` before starting the server.
- **Python packages required at runtime**: Ensure `python-decouple`, `PyJWT`, `webauthn`, and PostgreSQL adapter packages are installed in the target environment alongside Django.
